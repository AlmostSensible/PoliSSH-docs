# PoliSSH documentation

SSH, SFTP and remote editing on macOS. Choose your language to get started.

[Instrukcja po polsku](pl/guide.md){ .md-button .md-button--primary }
[English user guide](en/guide.md){ .md-button }

## Connect, work, transfer

- **Connections:** saved hosts, authentication profiles and server fingerprints.
- **Terminal:** local and SSH sessions, split panes and reusable commands.
- **Files:** SFTP transfers, conflict handling and remote text editing.
